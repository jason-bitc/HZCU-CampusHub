# 社区案件权限与状态机

2026-10-22。本批只实现案件提交、受理与基础流转，保留刘景浩的社区及管理网页主责和王晨的共享基础协调职责。自动化实现与测试不改正式负责人、人时、预算或整个工作包完成状态。

platform_user.role的USER约束和AuthService.me保持。管理账号和会话在独立表，令牌域和摘要独立；没有默认管理账号。审计增加actor_domain，历史默认USER；新管理审计明确COMMUNITY_ADMIN。运行请求、提交后变更和访问摘要也带主体域，两个表相同数字ID不混淆。

## 状态与结论

| 当前状态 | 动作及条件 | 新状态 |
| --- | --- | --- |
| OPEN | 任一有效管理员以当前revision认领 | PROCESSING，负责人为当前管理员 |
| PROCESSING | 当前负责人重复认领，当前revision | 无变化，保留修订／历史／审计 |
| PROCESSING／NEEDS_ACTION | 负责人释放，非空reason | OPEN，负责人清空 |
| PROCESSING／NEEDS_ACTION的FEEDBACK | 负责人ANSWERED／RECORDED，非空reply | CLOSED |
| PROCESSING／NEEDS_ACTION的REPORT | 负责人NO_VIOLATION／DUPLICATE，非空reply | CLOSED |
| PROCESSING／NEEDS_ACTION的REPORT | 负责人REQUIRES_GOVERNANCE，非空reply | NEEDS_ACTION，保留负责人 |
| CLOSED | 认领／释放／处理 | 拒绝 |

OPEN不能跳过认领直接处理。不同管理员不能释放或处理他人受理案件。expectedRevision和成功UUID回执共同防止覆盖；新键旧修订拒绝。NEEDS_ACTION表示后续治理交接，未隐藏原文、限制账号、扣贡献或返币。结论和公开答复必须描述实际处理，内部工作备注另存。

普通详情的历史只有revision、action、state、reply、outcome、occurredAt；不提供actorId、assigneeId、内部note或释放reason。管理详情按相同历史展示真实主体域、主体ID和内部记录。案件和历史无公开删除入口。

## 事务和快照

用户有目标提交先锁文章，再锁本人行；该文章的评论删除也锁文章，因此公开版本、评论可见性和必要上下文一致。无目标提交及上传只锁本人。锁内重查提交键、附件归属和绑定状态；文件逐一校验，成功后才绑定。图片无业务张数限制，更新按100行技术批次进行。

管理流转先锁案件，再锁当前管理账号，重查成功键和修订；登录及本机凭据重设按登录门闩→账号顺序，避免反向锁序。所有案件历史在最后阶段取得community序列锁，持有至提交，保证历史序号与提交顺序一致。caseId由创建历史序号确定；后续历史追加不改caseId。

案件内容／目标关联／证据绑定／创建回执／状态历史／管理回执／成功审计同事务提交。上传文件安装后登记事务回滚清理，只移除本次新生成文件；元数据或审计失败不会留下已受理的假结果。读取文件前验证身份和关联，大小及摘要不符或真实文件缺失明确失败。

只读查询用REPEATABLE_READ。snapshot是已提交历史上界，列表读取该界内每案最后状态，保留旧快照成员及状态；详情仍反映最新。没有以offset稳定性冒充冻结当前数据库。全局序列用于一致性，不构成性能达标结论。

## 目标和文件保护

首次举报仅接受当前公开版本及可见评论。管理员后续只能读取案件保存的曾公开版本，评论按当时可见正文和必要关系保存；从未公开草稿不进入快照。关联媒体只保存当时确实引用的文章／评论图片元数据，不复制整个图片库。原文件真实缺失时返回失败，不补造。

证据使用独立元数据与UUID，经同一JPEG／PNG真实性、MIME、单文件大小、像素、路径和软链接检查。文件根目录仍由当前MediaStore校验。未绑定仅上传者可读，绑定后由本人或案件管理入口受控读取；原文章和评论图片权限不变。

默认说明／备注上限10000码点，JSON2MiB，配置CAMPUSHUB_CASE_MAX_CODE_POINTS和CAMPUSHUB_CASE_JSON_MAX_BYTES启动校验；无最低字数或固定业务图片数量。单文件／multipart／像素边界见.env.example。

新动作接入Release／Debug安全日志。成功变更在afterCommit记录；失败有ROLLBACK而无成功审计。管理上下文与媒体成功访问只记录主体域、主体ID、caseId、对象类别及trace；不记录举报文字、reply、reason、内部note、截图内容、邮箱、密码或令牌。完整安全评估、平台性能压力、通知、申诉、荣誉及治理返还另行推进。
