# 非现金币规则与账目

2026-10-22，第八阶段。规则默认登录2币、阅读180秒领取1币，账号每日阅读奖励一次；两项合计3币。每人对同一文章终身累计最多2币，文章改稿、重新发布、日期或请求编号变化均不重置。无购买、充值、提现、现金兑换或读者自行撤回入口。

业务日期固定Asia/Shanghai，时刻以注入的服务端Clock为准。生产只有系统UTC时钟，测试通过受控Clock覆盖179／180秒与午夜，无调钟HTTP入口。成功登录写入的auth_session.created_at形成当日登录资格，复用旧会话跨日访问须先重新登录才能领当日登录奖；领取独立于登录响应，GET不发币。退出后仍须使用当前有效会话才能领取。

阅读开始要求当前公开且有有效公开版本；同人同文同日重复开始返回原会话。满门槛且当天未领，可领取一次阅读奖。不同文章与设备共用每日额度，昨日未领会话跨日不可领取。本人文章、无真实作者DEMO允许计时；文章在首次领取前不可用则404。这里只确认简单服务端计时资格。

初始钱包0；奖励加余额，投币减余额。作者收到的有效贡献从有效投币事实按author_id聚合，不再铸币到作者钱包；作者消费自己的奖励不减所收贡献。文章不可用不删除或自动返还既有贡献，恢复公开后继续汇总同一事实。荣誉等级、治理失效及返还后续实施。

## 幂等和事务

coin_event同时承担私人账本、经济事实和成功回执。其`(user_id,action,request_id)`唯一；成功同键同内容返回同一事件，包括原balanceAfter和原规则，不受午夜、重启、文章后续不可用影响。改目标、金额或阅读会话为409 REQUEST_KEY_REUSED。不同动作有独立键空间。失败事务没有成功行，同键可重试。

每日奖励还有`(user_id,action,reward_date)`唯一约束，投币额度在钱包锁内从该人该文累计支出计算；换键不能绕过。钱包balance>=0、事件余额及修订有数据库检查，钱包每次变动修订递增。私人历史只含标识、日期、数字与规则，不快照文章标题、正文或联系方式。

需要文章与钱包的事务统一按文章行→支出者钱包行加锁；登录奖只锁本人钱包；阅读开始只锁文章。不同文章共享同钱包仍会串行，不锁作者钱包、不以进程内锁代替数据库锁。READ_COMMITTED下拿到钱包锁后重查成功回执及额度，避免同键并发或换键绕过。文章锁与撤回共用，撤回先提交则新投币404；投币先提交则事实保留。

钱包更新、事件插入与business_audit成功审计同事务；阅读开始与其审计同事务。任何必要写入失败全部回滚，成功运行变更日志在afterCommit记录。贡献直接从已提交事件派生，避免另一个累加列失配。读接口使用只读REPEATABLE_READ保持单次响应一致。账本按本人事件sequence_id降序，使用snapshot上界固定后续分页，避免新增记录挤动旧页。

## 权限与日志

所有8类新动作均先校验有效普通校园认证，受限或认证失效拒绝；no-store，不接受他人userId。私有钱包、账本、投币状态不对游客开放；公共入口只返回文章聚合，无投币人名单。JSON上限4096字节，严格拒绝未知、重复、缺失字段和多余JSON值。

模块COIN的动作接入安全白名单，Debug有有限阶段与受控代码位置，Release保留请求摘要和提交后变更，不新增调试或诊断。日志不记录邮箱、密码、验证码、令牌、正文、完整账本或请求体。数据库审计保留最小actor/object及修订，运行文件只保存允许字段。完整平台性能、压力、荣誉、页面与设备验证分别安排。
