## 负载与稳定性实测

按 SRS 的 TC-NFR04、TC-NFR05 运行。起始样本为 200 个用户、2000 篇文章和 5000 条评论。使用 Java 21，应用堆上限 512 MiB，测试机有 16 个逻辑处理器。每个虚拟用户等待 200 毫秒后发下一次请求，循环执行列表、详情、评论读取及写入、草稿保存和奖励回执。压力和稳定性阶段沿用正常负载期间增长的数据。

正常负载满足读 P95 ≤ 1 秒、写 P95 ≤ 2 秒、非预期错误率 < 1% 的目标。单看正文草稿保存和评论写入，P95 分别为 93 和 141 毫秒。压力 30 并发阶段的 20 次客户端异常集中在阶段切换后的 36 毫秒内，样本未取得有效 HTTP 响应，错误率为 0.1351%。降载后的首个 10 秒窗口有 451 条请求，读写 P95 均为 47 毫秒，错误数为 0。

全程 213,103 次请求。最终记录 26,306 条评论、100 笔有效奖励流水，钱包与流水核对差异为 0，公开文章版本引用差异为 0。281 次进程采样中，应用与隔离 MySQL 的峰值工作集分别为 480.2 MiB 和 38.1 MiB。
