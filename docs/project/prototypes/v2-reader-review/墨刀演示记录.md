- 评审主线包含 A/B 和路径 1–4。
- 失败重试是同轮独立入口。

主原型由本轮设计导出图作底图，用墨刀原生链接区域绑定跳转。可编辑草稿中的 A/B 和文章首页保留编辑元素。免费版实际提示单个原型上限为 20 页和 300 个元素。A/B 的列表内容相同。B 当前可从入口打开同一 A01，完整筛选与回位的原生走查使用 A。主入口的其他状态按钮是展示位，失败用独立演示，其余状态从评审材料打开。桌面和 390px、分页加载、图片失败、空目录、内容不可用和 A01 全文另有画板，状态快照和全文源见 [画板索引](墨刀走查.md)。未测试未登录墨刀账号的访问，也没有真实用户结果、真实请求或任意滚动偏移恢复证据。

`modao-exports/` 保存从墨刀总览「导出」下载的 8 张原生 PNG。画板文件和本地导出位于 `boards/`，SVG 可缩放，对照 PNG 为 2×。使用已安装的 Python 与 Pillow 运行 `python render.py` 可重建 SVG 和热区坐标表。A01 正文来自项目已整理的公开资料，按原项目记录标注来源。
