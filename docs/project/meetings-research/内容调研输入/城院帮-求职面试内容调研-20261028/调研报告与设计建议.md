# 城院帮求职与面试内容调研

调研日期为2026年10月28日。本轮服务于发现页、文章阅读页、筛选与作者写作提示的设计。首批聚焦计算机相关岗位，保留跨专业扩展的结构。

## 本轮材料

入选13个来源，其中9篇个人记录来自8个不同账号，另有3份官方网页和1份官方视频文字稿。个人记录中8篇涉及2025至2026年，1篇为2022年的历史过程样本。不同记录不构成代表性抽样，不能据此计算行业录用率或统一招聘门槛。

同时保留6条待复核线索和7条排除记录。平台导航广告不自动等同于作者商业推广，审查重点放在正文、发布主体和可取得的来源链。个人记录保持当事人自述的身份，不将可读原帖等同于经历已获独立证实。

## 如何筛选

优先采用能追到本人原帖、说明岗位或过程，并留下具体提问、选择、困难或后续进展的材料。缺少作者信息的二次改写、机构训练内容、付费群或课程引流，以及依赖夸张承诺吸引点击的内容不进入页面素材。

只取得标题、简介、平台摘要或搜索片段的材料保留为线索。未播放的视频不填写观看时长，不根据标题编写视频总结。遇到转载先找原帖，找不到时不拿转载账号充当经历作者。

## 对小程序设计有用的发现

| 观察 | 来源 | 设计建议 |
| --- | --- | --- |
| 一段项目经历可以被继续追问动机、实现和个人负责范围 | S01、S03、S05 | 写作工具保留可跳过的提示，帮助作者把亲历写具体 |
| 面试当场记录与后续结果常常在不同时间更新 | S03、S04 | 区分经历时间、文章更新时间和当前结果，支持补充更新 |
| 目标方向与实际沟通岗位可能不同 | S07 | 岗位标签优先于公司标签，摘要说明实际经历的岗位 |
| 到岗条件和城市安排会影响选择 | S02、S06、S08 | 作为作者可选背景或正文信息，不把发布表单扩展成大量必填项 |
| 同一公司的不同岗位不能共用一套面试结论 | S10、S11 | 公司筛选保留岗位与经历日期，不生成统一难度或录用保证 |
| 评论适合补足经历中的缺失信息 | S03、S04的作者后续回复 | 让作者补充与普通评论区分，保留回复上下文 |
| 机构模拟面试与本人经验容易混在一起 | E02、S13 | 使用来源类型区分亲历、资料整理和官方教学，避免误认作者身份 |
| 招聘引流可能转向付费培训与贷款 | S12 | 避坑内容附可靠出处，举报入口沿用已讨论范围，不制作未经核实的企业黑名单 |

这些建议来自本轮内容分析，不是已经通过用户测试的结论。它们优先完善信息表达与现有功能，不自动变更项目需求基线。

## 内容组织

发现页以岗位为主要入口，保留公司、同专业与内容主题筛选。面试复盘、投递沟通、项目表达及求职避坑可以作为内容主题，不强制作者把每篇文章归入固定求职路径。

正文可以自然包含当时背景、准备过程、面试或投递节点、卡住的地方、后来调整及结果。写作工具提供几个可跳过的提示即可。来源、结果和经历时间优先服务读者判断，不能让标签数量压过标题与摘要。

同专业和相似基础的判断需要作者明确提供。账号上的兴趣标签、当前工作徽标、昵称和不真实的学校占位名称都不能代替当时的专业年级。没有取到的信息保留为空，不给外部作者增加校园认证。

## 各平台的实际覆盖

| 平台 | 本轮取得的材料 | 处理 |
| --- | --- | --- |
| 牛客及个人博客 | 可读个人原帖，另有少量只有摘要或页脚的链接 | 原帖入选；不完整链接留为待复核 |
| B站 | 第一份实习等视频元数据，直接访问部分页面返回412 | 未播放视频，不采用标题生成正文；交豆包补字幕核对 |
| 抖音 | 个人面试线索、平台摘要和明确的学员模拟面试文本 | 前两类待复核，模拟培训内容排除 |
| YouTube | Microsoft官方视频链接；Amazon官方视频及官网下载的完整配套文字稿 | 后者按文字稿使用，未声称观看画面；模拟教学与亲历分开 |
| X | 检索未取得符合条件的完整个人面经；出现过时招聘材料和无关内容 | 本轮无入选，不为覆盖平台凑数 |
| 企业与政府官网 | 招聘流程、质量岗位说明及求职风险提示 | 用于事实背景，不作为校内学生成功案例 |

## 已知内容缺口

本轮未取得可完整核验的浙大城市学院学生亲历，也没有足够的当前薪资、真实考勤和学校实习手续材料。不能从这些样本推导本校学生的录用概率、市场薪酬或校内办事规则。

豆包优先补充本校及杭州学生的完整经历、近两年第一份实习的准备过程、普通企业与中小团队案例，以及能够核对字幕的个人视频。失败、仍在准备和岗位不匹配的经历应保留，避免素材只剩少数大厂成功者。

## 用于页面预览的方式

本包整理13条卡片，C01、C05、C08附较完整的阅读正文，其余适合列表、摘要和原文入口。所有卡片统一署名“城院帮资料整理”，附原始出处，不将外部作者冒充本校作者。

互动计数、联系方式、认证状态和作者专业年级没有取得可靠数据时不补造。JSON为设计资料结构，不替代既有后端接口。没有正文的短卡不能拉伸成假长文，也不通过复制段落撑长页面。

原文不整篇搬运。公开展示采用本包的独立概括和原文链接，若需转载完整原文或视频画面，应另行取得相应授权。本文本包不含原帖原文全文、原视频及官方文字稿的完整副本。
