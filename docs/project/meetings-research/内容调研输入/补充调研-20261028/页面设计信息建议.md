# 城院帮 · 补充调研｜页面设计信息建议（uni-app 小程序 + 网页）

> 目标：把 S14–S25 的真实材料落到“标题 / 摘要 / 标签 / 正文 / 作者可跳过的写作提示”上。原则：不编造、不整篇搬运、不把平台自动摘要当原话；弱基础、失败、无结果内容与成功内容同等保留；不做统一题库、薪资标准、公司黑名单。

---

## 一、各字段取材建议

### 1. 标题（卡片标题 / 详情页 H1）
- **用“身份 + 阶段 + 结果状态”的克制写法**，不用“逆袭/爆杀/稳了/血泪史”等夸张词。
- 结果状态要可核验：拿到 offer、通过但拒了、面试挂、还在等、刚入职。
- 推荐范式（均为编辑据事实改写，非作者原话）：
  - “双非本211硕·Java：两段实习后秋招签约拼多多（S14）”
  - “在杭高校·测开：杭州网易伏羲两轮面经（S15）”
  - “C++：海康威视一天两面、两天拿offer（S16）”
  - “杭州小厂·前端：两位面试官各30分钟（S17）”
  - “前端面杭州凌迪：通过，但因无转正拒了（S18）”
  - “普通本科·运维：12分钟面试后入职（S19）”
  - “大二·安卓：腾讯WXG三轮面经（S20）”
  - “浙工大·Java：起步晚的求职复盘（S21）”
  - “大四·C++游戏引擎：HR面后等待结果（S22）”
  - “民办本科·Java：杭州小厂发offer（S23）”
  - “近50场面试后：快手一二三面oc（S24）”
  - “六七人初创·软件开发：入职第一天（S25）”
- **不要**把“晒收入/只晒offer/保offer”类做成标题。

### 2. 摘要（卡片 1–2 行，50–100 字）
- 直接采用《独立摘要与读者追问.md》中的独立摘要，已控制在 50–100 字。
- 摘要必须含“当时基础/背景 + 过程 + 结果状态”三要素中的至少两项；无结果的明确写“结果未知/等待中”。
- 弱基础与失败案例的摘要不做“先抑后扬”的广告化处理。

### 3. 标签（筛选/聚合用，建议固定受控词表）
- **岗位标签**：Java后端、前端、C++、测试开发、软件测试、运维/SRE、安卓、iOS、算法、大数据、数据开发、Go、Python、音视频、嵌入式、安全、DBA。
- **阶段标签**：第一份实习、日常实习、暑期实习、秋招、春招、投递中、面试复盘、入职体验、拒offer、失败复盘。
- **地区标签**：杭州、上海、广州、深圳、成都、南京、远程/线上面试。
- **学校标签**：本校（HZCU）、在杭高校、其他高校；**未核实到本校前不创建“本校”标签下的内容**。
- **结果标签**：已offer、已OC、通过但拒绝、面试挂、等待结果、刚入职。
- 每条建议打 3–5 个标签（岗位+阶段+地区+结果），避免堆砌。

### 4. 正文（详情页，结构化模块）
建议固定模块，作者可按实际情况留空，不强制：
1. **我的背景**：专业/年级/学校（可匿名）、当时技术栈、是否有实习/竞赛。
2. **准备过程**：学了什么、做了什么项目、准备了多久。
3. **投递渠道**：BOSS、官网、牛客/力扣、校招群、人脉内推等；不写付费内推。
4. **面试经过**：轮次、形式、被问到的点（标注“本人回忆”），不追求标准答案。
5. **失败与调整**：挂在哪、之后怎么改。
6. **实习体验 / 入职后**：实际做什么、带教、节奏。
7. **结果与后续**：offer/拒/等待，及后续更新时间。
8. **来源与核验**：原平台、原作者、链接、提取程度（全文/字幕/简介）、更新日期。
- 视频类内容在正文顶部用徽章标注“实际观看 / 字幕已读 / 仅简介”，并在引用处给字幕来源与时间段。

### 5. 作者可跳过的写作提示（选填，不强制回答）
- “可以只写你记得最清楚的一轮，不必补全所有轮次。”
- “不确定的公司名、时间、薪资可以留空，不用勉强回忆。”
- “如果还在等结果，就写‘等待中’，后续可以更新。”
- “可以写‘这题我没答上来’，这是对读者最有用的部分之一。”
- “不想公开学校可以匿名，但请不要填成其他学校。”
- 这些是**可跳过**提示，避免把作者逼成“必须写满”或诱导编造。

## 三、应明确跳过 / 不做的内容

- **跳过**：培训机构推流、课程/付费群/资料包口令、保 offer、付费内推、购买实习证明、学员模拟案例（对应 E10、E13、E16）。
- **跳过**：只晒收入/offer、无过程、标题夸张的内容作为核心样本。
- **跳过**：把面经题目整理成“统一题库/标准答案”；把零散薪资做成“薪资标准”；把个案拼成“公司黑名单”。
- **跳过**：平台自动生成的“视频摘要/AI 总结”作为作者原话（S25 仅为平台返回文字，已标注未实际观看）。
- **跳过**：评论区第三方工具/面经库链接（如 S17 评论中的 pinkprisma），不代表作者背书。
- **不做**：伪造“读者评论/问答社区假象”；读者追问仅作为编辑整理的问题单列。
- **身份红线**：未核实到浙大城市学院（HZCU）学生本人原帖前，不把任何外校经历改写或标注为“本校”。
