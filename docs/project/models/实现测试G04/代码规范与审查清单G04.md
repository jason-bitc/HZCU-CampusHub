| 检查范围 | 核对要求 |
| --- | --- |
| Java 与数据库 | 入口、服务和持久层职责分明。SQL 参数化，事务统一提交，迁移编号、状态变更和索引同步。 |

| 审查证据 | 至少保存源码版本、定位、问题、处理人、修订和复核。通过结论由实际复核者填写。 |
