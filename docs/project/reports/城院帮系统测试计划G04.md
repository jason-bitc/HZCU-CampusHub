# 1 测试策略

范围为 SRS V1.5.1 的 50 项本期功能、12 项非功能及关联业务规则。FR-A03 和 FR-M05 为后续扩展项。用例沿需求编号、设计模块、步骤和证据回查。单元层验证可隔离判断，集成层使用真实 MySQL 和受控运维环境验证持久化、事务与权限，系统层由两个终端走通业务并核对数据。功能修订后重跑受影响用例和回归集。


## 1.1 三级测试的工具和责任

| 层级 | 方法和工具 | 责任 |
| --- | --- | --- |
| 单元 | JUnit 及前端既有检查。对解析、状态、权限分支、边界及冲突设计白盒用例，保存覆盖与结果。 | 两人测试各自负责的模块，互相走查高风险用例 |
| 集成 | Maven 集成测试、隔离 MySQL、Postman，核对 HTTP、SQL、事务和接口授权。 | 王晨组织业务，刘景浩组织治理与运维，交叉复核 |
| 系统 | 微信开发者工具、桌面浏览器和实际设备，按角色逐步走查。 | 刘景浩组织终端，王晨复核接口、数据和异常 |
| 性能及恢复 | JMeter 或等效负载工具、资源趋势记录、隔离恢复演练。 | 按 6.2、6.3、6.5 责任与分配执行 |

# 2 测试方案与环境


## 2.1 环境与测试数据

使用本机演示环境副本和独立测试库。记录 Git 版本、MySQL 与 Java 版本、设备、端口、资源、测试数据版本与起止时间。功能样本覆盖访客、认证读者、作者、社区管理员和运维人员。固定性能数据为 200 用户、2,000 文章、5,000 评论。邮件收发、图片传输和长任务单独测量。准备有效与失效会话、不同文章状态、合法和损坏备份，以及可供恢复前后核对的样本。


## 2.2 执行场景与验证方式

| 用例 | 执行场景 | 环境、工具及责任 |
| --- | --- | --- |
| TC-NFR01／11 | 跨身份访问评论、联系方式、他人草稿及运维任务；检查返回和日志隐私 | 隔离 API、两端、Postman；王晨与刘景浩交叉执行 |
| TC-NFR02 | 旧修订发布、同键重复投币、失败不扣币、两名管理员竞争处置 | MySQL 集成和接口，王晨核对事务，刘景浩核对治理 |
| TC-NFR03 | 校验内容与图片格式、文件授权和失败反馈 | 合成文本和测试图片，接口与两端，刘景浩验证 |
| TC-NFR04 | 30 并发，60 秒升载后稳定运行 10 分钟；读写分别统计 | 固定数据、JMeter 或等效工具，王晨 |
| TC-NFR05 | 10、30、50、100 并发各 2 分钟，再以 10 并发运行稳定性用例 30 分钟 | 固定数据、独立负载与资源记录，王晨主测 |
| TC-NFR06／07 | 双端检索、阅读、图片和发布；网络失败后草稿可恢复，旧修订保留输入 | 微信工具、实际设备与浏览器，刘景浩主测 |
| TC-NFR08 | 业务停机，访问独立运维网页、查询状态与已有任务 | 隔离进程和浏览器，刘景浩主测，王晨复核 |
| TC-NFR09 | 校验正常和损坏备份，隔离恢复，核对版本、SQL 和图片 | MySQL 工具、运维任务日志与计时，刘景浩与王晨 |

# 3 预期结果与证据


## 3.1 验收指标与证据

| 验收内容 | 预期结果 | 应保存的证据 |
| --- | --- | --- |
| 角色和隐私 | 访客仅读取公开正文，私有资料、凭证和证据按角色隔离 | 响应、权限矩阵、脱敏截图 |
| 内容和账本 | 修订冲突保留编辑输入和公开旧版；同键只产生一次副作用；状态和账本一致 | 接口回执、版本快照、账本与数据库核对 |
| 30 并发常规负载 | 读 P95 ≤ 1 秒，写 P95 ≤ 2 秒，非预期错误率低于 1% | 场景配置、负载原始数据、P95 和错误率 |
| 阶梯压力与稳定性 | 记录各级响应、吞吐、资源和边界；100 并发用于探测；10 并发持续 30 分钟数据一致；降至 10 并发后 2 分钟内恢复 | 趋势、降载时间和一致性核查 |
| 双端与独立运维 | 两端核心操作可完成，错误可分辨；业务停机仍能访问运维状态和任务 | 环境记录、原生和网页截图、响应与任务号 |
| 备份与恢复 | RPO ≤ 24 小时、RTO ≤ 10 分钟；每日备份，重要变更前另备；保留 7 份成功备份和 1 份离机副本；损坏备份拒绝 | 清单、备份时点、计时、样本校验及离机副本记录 |


## 3.2 通过条件与执行登记

单元测试的预期与实际逐条登记。通过条件为断言符合预期、没有阻断问题、关键路径完成，并保存可追溯证据。未测项目登记环境、缺口及后续责任。每条执行记录至少包含用例号、版本、环境、执行人、时间、结果、缺陷号和证据路径。
