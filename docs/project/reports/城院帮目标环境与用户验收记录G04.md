# 1 目标环境检查

6.4.3 由刘景浩组织目标设备和网络核查，王晨提供构建及版本信息。把小程序、读者网页、社区管理和独立运维入口的版本、设备、系统、浏览器、网络和样本分别登记。模拟器记录按原环境标注。实际设备、生产式本机演示和候选版本结果分别取证。


## 1.1 设备环境与证据

| 项目 | 核查方式 | 证据 |
| --- | --- | --- |
| 小程序 | 从发现页筛选、读到正文末尾，在已授权环境尝试草稿和图片 | 设备与微信版本、过程截图 |
| 读者作者网页 | 登录、文章、工作区和跨端修订冲突 | 浏览器版本、构建与步骤 |
| 社区治理 | 管理员定位关联内容及受控处理 | 管理入口、案件或样本编号 |
| 独立运维 | 隔离环境中核对停机状态、备份和恢复说明 | 独立访问地址、健康和阶段结果 |

# 2 最终用户任务走查

6.7.1 以真实参与者的角色代号记录。先给目标任务，记录参与者是否独立完成、耗时、卡点和意见。涉及真实身份信息时只保留必要的确认方式和脱敏记录。


## 2.1 角色、任务及完成条件

| 角色 | 任务 | 可观察的完成条件 |
| --- | --- | --- |
| 读者 | 找到相同专业或意向岗位的经验，阅读并收藏 | 找到相关文章，能返回并再次打开 |
| 作者 | 撰写图文草稿，从另一端继续或处理版本冲突 | 输入可恢复，能解释发布与冲突反馈 |
| 社区管理角色 | 从举报打开关联文章和评论，处理并查看历史 | 关联对象准确，理由及审计可查 |
| 运维角色 | 在隔离环境查询停机状态与恢复记录 | 区分受理、处理中、失败和终态 |
