## 4.2 小程序第二轮交互优化

本轮从 `650ddfd` 继续，完成提交 `78eb599` 并推送 `feat/ljh-miniprogram-ux`。修改前后和复现步骤以小程序专项验收记录为准。

| 页面 | 原问题 | 本轮结果 |
| --- | --- | --- |
| 发现与筛选 M01–M04 | 不同空态共用提示；刷新或下一页失败可能破坏已读状态；返回位置可能被过渡事件覆盖 | 区分无公开内容、筛选无匹配和接口失败；失败保留条件及已读页；读完返回保留列表和滚动位置 |
| 长文阅读 M05–M06 | 互动反馈位于文首，长文底部操作后不易看到结果 | 底栏显示处理状态和结果；保留右上角 44×44 CSS 像素目录并标出当前章节；游客登录后回到原文原章节 |
| 图文创作 M20–M25 | 发布缺项共用返回入口；上传状态不细致；恢复提示可能影响本机副本 | 缺项逐项直达字段，图片逐张显示上传和重试；真实 409 后保留原正文、新输入和图片引用并定位到版本对比 |
| 通知与申诉 M16、M29–M31 | 刷新失败清空通知；目标入口和撤销状态不明确 | 保留上次结果，区分未读与处理结果并按目标跳转；认证撤销账号可查看原因、通知和复核答复 |

本轮结果属于自动检查、320 CSS 像素模拟器和真实 8080 接口的组内验收。PR #42 尚待评审，真机、真实用户、校园邮箱、手机相册选图和实际扣币复测不能据此标记通过。
