4 数据字典

4.1 定义记号与组合结构

“+”表示按序组成，“[a|b]”表示择一，“{x}”表示零到多次重复，“1{x}”表示至少一次，“(x)”表示可选，“=”表示定义。此处的结构定义与正则分开，避免将关系和重复记录塞进单个正则。

| 结构名 | 结构定义 |

| ArticleInput | title + jobId + (companyId) + (majorId) + experienceStage + startingPoint + 1{ContentBlock} + expectedRevision |

| ContentBlock | [TextBlock|ImageRef|SourceLink] |

| TextBlock | text |

| ImageRef | mediaId + position + (caption) |

| SourceLink | url + description |

| AuthInput | email + password + challengeId + code |

| InteractionInput | articleId + [CommentInput|ReactionInput|CoinInput|RewardInput|ContactQuery] |

| CoinInput | amount + requestKey；amount∈{1,2}，累计而非单次额度≤2 |

| CaseInput | kind + targetType + (targetId) + reason + {EvidenceImage} |

| OpsInput | operation + target + requestKey + (backupId) + confirmation |
