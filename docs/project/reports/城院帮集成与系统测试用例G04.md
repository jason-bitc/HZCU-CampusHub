# 1 使用与覆盖


## 1.1 需求覆盖与取证口径

本文件以 SRS V1.5.1、总体设计 V1.2.1 和项目计划 V1.8 为输入，覆盖 50 项本期功能与 12 项非功能。FR-A03、FR-M05 属于扩展，保留在 SRS。用例编号沿用原需求追踪矩阵。提交前记录候选构建、环境、样本、执行人和证据，执行结果另填。


## 1.2 集成与系统环境

集成环境使用隔离 MySQL 和受控进程。接口记录应保存方法、状态、时间及版本，账号和私有内容使用合成数据。系统环境按候选版本覆盖微信开发者工具、网页、目标设备与独立运维。实际执行结果登记在《测试结果缺陷与复测记录》。

| TC-R06 认证阅读边界。有评论和联系设置的公开文章 | 访客阅读正文后尝试展开受限项；校园认证后访问同一文章 | 未认证响应和页面数据不含受限字段；认证后可以查看；作者资料限制不影响免费全文阅读。 取证 公开字段与认证字段对照 |

# 4 图文创作

| 用例与准备 | 操作 | 预期及取证 |
| --- | --- | --- |
| TC-C01 轻量发布信息。认证作者和空草稿 | 只填写必填内容试发布；再缺一项试发布并核对表单保留 | 普通经验可用少量必要信息发布；无公司、无联系方式及未使用提示仍可发布；经历阶段可独立确认。 取证 发布结果与缺项提示 |
| TC-C02 网页Markdown创作。网页作者及带标题、列表和代码的合成正文 | 在网页编辑并预览 Markdown，保存后在小程序阅读预览或公开正文 | 编辑和预览一致，公开页面安全呈现；图文及代码可读；失败后能恢复编辑内容。 取证 编辑、预览、跨端渲染证据 |
| TC-C03 小程序基础图文创作。小程序作者、两张合成图片 | 写文字并插图，保存草稿，重新打开并预览发布 | 没有电脑也能完成基础图文文章；移动端查看网页文章正常；不支持的编辑场景不会损坏已有正文。 取证 移动编辑、图片引用和发布回执 |
| TC-C04 图片上传与失败处理。正常图片、服务端拒绝的测试文件、可切换网络 | 正常上传后触发失败，检查草稿和正文；恢复网络后重试失败项 | 多图成功与部分失败均有明确状态；重试不重复产生图片引用；图片访问遵循所在内容的权限。 取证 两种结果、草稿状态及重试记录 |
| TC-C05 多草稿保存与恢复。同一作者的两篇草稿 | 分别保存，在另一端重开；模拟保存中断后重新进入创作页 | 多个草稿互不覆盖；保存失败后内容可找回；刷新、重入及重新登录场景不静默清空正文。 取证 两个草稿的区分和恢复记录 |
| TC-C06 预览与发布。一份完整草稿和可检查的版本计数 | 先预览后发布；重复提交同一发布请求并核对公开版本数 | 合法文章发布后公开可读；草稿不公开；重复提交只形成一次发布；无需逐篇人工预审。 取证 预览、发布回执、版本变化 |
| TC-C07 修改与版本冲突。两端打开同一修订 | 端一保存，端二使用旧修订保存；对照端二输入、服务端版本和公开页 | 两个设备同时修改同文能识别冲突；确认前公开版本保持一致；失败不会留下半更新状态。 取证 冲突提示、草稿和旧公开版 |
| TC-C08 下架删除与恢复权限。本人文章、另一作者和社区管理员 | 本人下架后看访客页，再按许可恢复；核对非作者和管理处置的边界 | 自主下架不再公开；作者恢复限本人自主下架内容；管理员隐藏内容只能经授权处理恢复。 取证 角色状态与文章前后记录 |
| TC-C09 可跳过写作提示。有写作提示的空草稿 | 打开提示后选择跳过，继续编辑并预览；回到草稿检查输入 | 不使用提示能完成发布；使用提示不增加固定审核流程；提示不会覆盖已有正文。 取证 跳过、保留输入与编辑状态 |

# 5 交流与联系

| 用例与准备 | 操作 | 预期及取证 |
| --- | --- | --- |
| TC-I01 评论与回复。认证读者和一篇公开文章 | 提交文字及图片评论，回复已有评论；再次打开详情确认层级 | 合法用户可交流并看到回复关系；未认证不能读取或新增；失败不会产生重复评论。 取证 评论、回复、图片和刷新记录 |
| TC-I02 评论管理边界。评论作者、其他读者、社区管理员 | 分别尝试管理同一评论并核对可见状态和管理记录 | 作者删他人评论被拒绝；本人操作只影响本人内容；管理员操作可追溯，回复上下文可辨认。 取证 三角色的权限结果与历史记录 |
| TC-I03 点赞认可。已有点赞数的公开文章 | 点一次赞后重复点击或刷新，取消再刷新，核对计数及本人状态 | 连续重复点赞计数不膨胀；取消后相应计数减少；不会扣币或自动收藏。 取证 赞状态和计数前后对照 |
| TC-I04 收藏与重访。两篇公开文章和已认证账号 | 收藏一篇，在另一个端重访，取消后刷新收藏列表 | 收藏与取消结果一致；未认证不能操作或读取他人收藏；失效收藏不会自动删除治理记录。 取证 双端收藏状态与返回路径 |
| TC-I05 作者公开主页。已配置资料的作者 | 访客和认证用户分别从文章进入作者区域，核对授权展示字段 | 认证用户可进入；访客及未认证不能通过页面或直接请求取得主页资料；隐藏文章不在公开列表出现。 取证 作者页及角色字段对照 |
| TC-I06 作者联系开关。作者和可查看联系入口的读者 | 作者开启并保存联系设置，读者查看；关闭后刷新同一作者页 | 无联系方式文章可发布；开启后认证用户可查看；关闭后接口和新页面均不返回联系字段。 取证 开启和关闭前后记录 |
| TC-I07 自愿站外联系。联系设置已开启的合成联系方式 | 进入联系入口，核对说明，复制后离开；关闭时再查看 | 可自愿复制合法公开信息；没有站内支付、视频、即时聊天或咨询履约流程。 取证 联系提示和关闭状态，不保存私密内容 |

| TC-G06 贡献失效与追溯。可追踪的有效贡献和一条失效事件 | 管理端按规则标记失效，核对作者计数、事件关联与历史 | 贡献修正有原因、责任人和关联记录；计数、排序和荣誉一致；没有无说明的余额变化。 取证 贡献差额、失效理由和审计记录 |
