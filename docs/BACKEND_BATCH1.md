## 结构与实现依据

article模块分Controller接口、Service只读事务、Repository参数绑定查询；common提供配置校验、统一响应及异常、请求追踪、健康响应。使用官方正式版4.1.1，其[系统要求](https://docs.spring.io/spring-boot/system-requirements.html)支持Java 21；依赖已经实际下载、编译并打包，没有采用预览版。

库模型限文章读取：article保存状态、公开版本和演示计数；article_version保存标题、摘要、Markdown正文、经历阶段、来源与发布时间；category及版本关联覆盖四种分类；article_source_link提供版本资料来源。公开版本通过复合外键归属于该文章。作者账号关系、图片文件管理、写操作和治理审计待后续设计，不以当前空缺字段伪称完整功能。

公开列表和详情始终以PUBLISHED及当前已发布版本查询，草稿修订不会改变公开标题、标签或正文。多次查询放在同一只读REPEATABLE_READ事务，排序具有稳定id兜底。所有筛选值参数绑定，排序仅选固定SQL分支。keyword中的LIKE通配符按字面转义。

默认本机演示；本轮没有部署腾讯云、修改其他项目服务或开发独立运维网页。自动测试通过测试应用专用TCP代理制造连接故障，MySQL服务保持运行。
