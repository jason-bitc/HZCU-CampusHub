## 2 必要业务

### 2.1 从文章找到作者

保留现有游客文章列表和详情合同，不向游客响应加入作者账号、昵称、主页或联系方式。单设需要认证的文章作者入口，避免同一游客响应因登录状态不同而泄漏资料。

认证读者从仍然公开的文章取得该文真实作者的最小主页入口。没有真实作者关联的旧演示文章不分配给王晨、刘景浩或虚构校友，入口返回不可用；正文继续按现有规则免费阅读。

### 2.2 作者主页与文章列表

主页只返回昵称、专业、当前在校或毕业阶段、简介、校园认证状态，以及当前公开文章数量。沿用现有资料字段；不扩展头像、履历核验、年级体系或勋章计算，不虚构荣誉和工作经历。认证只代表校园关联身份。

主页及作者文章列表均需当前有效的普通用户身份、ACTIVE账号与VALID校园认证。目标作者账号与认证同样正常，并至少有一篇当前公开文章；其他情况返回统一404，不暴露账号存在性及限制原因。作者本人无公开文章时仍可通过原 `/me/profile` 管理自己的资料。

作者文章只列当前PUBLISHED且有有效公开版本的内容，不列草稿、本人下架、管理员隐藏、删除或其他人的文章。分页默认20、最大100，按首发时间及文章ID降序，稳定数据下顺序确定；不以草稿更新时间或恢复时间冒充新发布。

### 2.3 作者可选联系方式

联系方式与基础资料分开保存、独立修订，避免旧客户端完整保存资料时清空联系设置。默认为关闭；不提供联系方式不影响发文。

本批先支持单个联系方式：微信号、QQ号或站外网页链接，作者可自行修改和关闭。微信号与QQ号作为普通文本展示及复制；网页链接只接受有效的绝对HTTP/HTTPS地址，不含用户凭据，不提供任意跳转或服务端抓取。二维码、联系图片、多联系方式及站内沟通留待后续。

建议实施默认参数：文本值去首尾空白后非空、最多200个Unicode码点；网页地址最多2000个码点；拒绝控制字符。参数是本批技术默认值，需在接口文档记录，不表述成教师已确认要求。

作者本人可读取和修改保存的联系设置。认证读者仅在目标作者可见且联系开启时取得公开值；关闭时仅返回关闭状态，响应不带type/value等联系内容。联系设置更新成功后启动的新读取必须看到最新设置，不得使用旧公开快照或缓存返回关闭前的值；已下载或复制到站外的信息不承诺收回。

### 2.4 权限与操作日志

沿用现有会话、认证及统一错误体系，不建立第二套登录机制。当前会话每次请求都重新核验；无有效登录401，访问者账号或认证受限403，目标不可见404，旧修订409。先检查访问者权限，再查询受限目标，避免错误区别泄漏资料。

所有新增受限接口及其失败响应使用 `Cache-Control: no-store`，不把Bearer令牌放在URL。主页和文章摘要不夹带完整用户对象、真实邮箱、认证时间明细、密码摘要、角色凭据、收藏或联系方式。

建立可复用的业务审计基础，本批覆盖联系设置修改、基础资料修改、文章发布/下架/恢复/删除。成功审计与对应数据库状态变更在同一事务内写入；审计写入失败时不返回业务成功。同一重试仅有一次实际状态变化时，不制造多条成功变更记录；无变化重试与失败尝试可在运行日志区分。

审计至少保存事件标识、UTC时间、traceId、操作者内部标识、动作、对象类型和标识、前后状态或修订、结果。仅记录状态及修订等白名单元数据，不保存昵称旧值、联系方式原文、文章正文、图片内容、请求体、验证码、SMTP口令或令牌。权限拒绝和异常通过脱敏运行日志关联traceId；不要拼接完整URL、查询参数、数据库异常消息或用户输入。

本批可提供可配置文件日志及轮转的实现默认值，并验证实际输出、重启保留及隔离目录故障；独立运维日志查询网页、治理审计和运维执行器仍由刘景浩后续实现。不向普通账号新增日志下载或审计查询接口。完整日志系统是否完成，应逐项对照原日志验收要求，不能仅有请求耗时日志就记为完成。

## 3 接口契约草案

全部使用 `/api/v1`、原统一响应及X-Trace-Id。此表是实施契约，开发者可在不降低权限和完成标准的前提下微调字段，最终同步API与Postman。

| 接口 | 主要结果与边界 |
| --- | --- |
| GET /articles/{articleId}/author | 认证读者取得 `{authorId,nickname}`；非公开文章、无真实作者或不可见作者404。游客原详情保持不变。 |
| GET /authors/{authorId} | 受认证限制的作者主页白名单字段；含公开文章数量，不含联系方式和未实现荣誉。 |
| GET /authors/{authorId}/articles?page=1&size=20 | 认证后读取该作者当前公开文章；分页结构复用原文章列表。 |
| GET /me/contact-settings | 本人的 `{revision,enabled,type,value}`；未设置时revision=0、enabled=false、type/value为空。 |
| PUT /me/contact-settings | 完整替换 `{expectedRevision,enabled,type,value}`；仅能改本人，独立revision。关闭时允许保留原值或明确清空；开启必须有合法值。 |
| GET /authors/{authorId}/contact | 目标作者可见后，返回 `{enabled:false}` 或 `{enabled:true,type,value}`；禁用时不返回隐藏字段。 |

原 `/me/profile` 的请求和返回保持兼容，不在其完整替换中强制新增联系字段。作者列表不开放未实现的筛选或勋章参数；未知参数、重复参数、无效分页与非法ID沿用严格校验策略。

## 4 数据与兼容

仅新增V5或实际下一个未占用的Flyway版本，不改V1—V4和原演示迁移。建议新增独立联系设置表和业务审计表，约束用户归属、revision及联系开关与类型的一致性；必要索引服务作者公开文章查询。业务数据与日志记录不使用邮箱作为公开作者标识。

资料或联系设置不存在时GET不悄悄建账号或改认证。作者主页使用当前允许公开的资料，联系方式每次单独按实时开关查询；文章公开版本不保存联系方式快照。旧草稿、图文版本、图片权限、创建/上传/发布回执和演示计数语义均保留。

既有文章读取接口必须继续免费且不含身份字段。没有互动实现时，继续保持真实文章NONE/0、旧演示DEMO计数，不通过本批日志或主页访问伪造投币、点赞或阅读奖励。
