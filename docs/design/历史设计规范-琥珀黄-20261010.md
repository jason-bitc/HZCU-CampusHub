# Design System: 城院帮

## Overview

**Creative North Star: "认真整理的学长学姐经验册"**

用户已选择 F 琥珀黄。当前世界以白底、深色中文、少量琥珀黄强调和全宽文字列表呈现清爽、有品质的经验社区。标题、摘要、章节与留白承担信息层级，文章列表没有左右封面或图片列，首页不添加装饰插画。

本文件是唯一活动设计规范，依据 [产品范围](PRODUCT.md)、[无封面布局与配色说明](docs/design/无封面布局与配色说明.md) 及 [琥珀黄无封面四页概念图](docs/design/城院帮-琥珀黄无封面四页.png) 记录当前选定方向。说明文件中旧的“待选择”状态已被本次选择覆盖，历史视觉稿不作为当前实现依据。前端页面交付参照 [WorkBuddy 页面开发指令](docs/design/WorkBuddy-琥珀黄页面开发指令.md)；WorkBuddy 仅负责前端，后端由 GPT 协助实现。

最终图仍是 AI 生成概念图，没有可点击原型或前端源码，不代表功能已实现或经真机验证。人物、文章、认证状态、互动数均为虚构演示数据。图像中的颜色、样式、文案或权限偏差以本文件及产品范围为准。

**Key Characteristics:**

- 白底深色文字，琥珀黄突出选中与主要操作。
- 全宽标题与摘要，使用间距和细分隔线组织经验条目。
- 中文系统字体、姓名字符头像及统一线性功能图标。

## Colors

下表为用户选定方案的指定色值，不是图片取样或从实现代码提取的 token。

| 角色 | 规范值 | 用途 |
| --- | --- | --- |
| Primary · 琥珀黄 | `#E3B33D` | 主要按钮填色、选中筛选与小面积品牌强调 |
| Primary · 深琥珀 | `#805A10` | 功能强调图标、文字与当前导航项 |
| Secondary · 浅琥珀 | `#FFF4D5` | 标签和轻量提示底色 |
| Neutral · 白色 | `#FFFFFF` | 页面与内容底色 |
| Neutral · 深墨色 | `#26231C` | 正文、标题及黄底按钮文字 |
| Neutral · 暖灰 | `#6B6250` | 次文字与元信息 |
| Neutral · 浅中性灰 | `#F4F3F0` | 搜索等中性控件底色 |
| Neutral · 淡灰 | `#E6E5E1` | 分隔线 |

指定值计算的对比度为：正文／黄底（8.05:1）、深琥珀／白底（6.20:1）、次文字／白底（6.02:1）、正文／白底（15.68:1）。白字／黄底仅（1.95:1），禁止黄底白字。这些数值来自指定色值计算，不代表图像取样结果或真实页面验证。

**The Legible Amber Rule.** 黄底按钮使用深墨文字；白底功能图标与文字使用深琥珀，不照搬生成图中过浅的黄色。

**The Clear State Rule.** 状态同时通过信息与颜色表达；选中、认证和异常须有文字、图标或明确形态，不能只靠颜色。

## Typography

有意选择原生系统中文无衬线字体，保障中文覆盖、加载速度和平台阅读习惯。iOS 优先 PingFang SC，Android 使用平台中文无衬线字体；不引入装饰性网络字体。图像字体效果不代表已加载真实字体。

| 层级 | 规格 | 用途 |
| --- | --- | --- |
| 页面标题 | 24px | 页面主标题 |
| 详情标题 | 22px | 文章题目 |
| 列表标题 | 17–18px；行高约 1.45 | 经验条目 |
| 正文 | 16px；行高约 1.7–1.8 | 长文阅读 |
| 辅助信息 | 12–13px | 作者、日期与标签 |

标题加重建立层级，具体字重待实现确认。长标题和专业名称允许换行，必要时提供完整值的查看方式。

## Layout

以 390px 画板、两侧 20px 边距为参考，使用 4、8、12、16、24、32px 间距尺度。文章列表的标题和摘要从左侧边距开始占满内容宽度，下方排列岗位／主题标签、作者和互动信息。不预留图片列，不在右侧补回封面。首页不使用校园场景插画或大色块宣传头图。

| 页面 | 信息层级 |
| --- | --- |
| 发现 | 品牌与短引导 → 搜索 → 岗位筛选 → 同专业／公司次级筛选 → 重点经验与连续全宽列表 → 底部导航 |
| 经验详情 | 岗位与阶段、题目、作者及阅读信息 → 摘要 → 准备／投递／面试／避坑目录与正文 → 点赞、非现金投币、收藏、评论 |
| 作者主页 | 姓名字符头像、昵称、专业与背景 → 经验及互动概览 → 作者选择公开的联系方式 → 无封面的经验列表 |
| 我的 | 本人信息与认证状态 → 收藏／经验／草稿 → 非现金币及轻量每日奖励 → 写作入口 → 反馈与设置 → 底部导航 |

底部导航为“发现／收藏／创作／我的”。所有文章列表沿用全宽无封面规则；该规则不限制文章正文内的必要图文。布局需在正式开发时转换适配，不能将 px 简单翻倍视为适配完成；小屏幕、长文案、中文字体、微信胶囊及底部安全区仍需验证。

## Elevation & Depth

图中主要以白色表面、浅标签／提示底色、留白与细分隔线建立秩序。外部展示画板的投影不属于小程序阴影规范。没有精确阴影参数，不据概念图引入重阴影、磨砂玻璃、渐变或发光装饰。

## Shapes

内容容器使用温和圆角（16px），短筛选标签可使用胶囊形。头像可先用姓名字符圆标，不要求真人照片。正文与列表不逐段包成独立圆角卡片，依靠连续阅读节奏组织。

## Do's and Don'ts

### Do:

- **Do** 功能图标采用统一线性样式，线宽约 1.5–2px；选中项结合文字与形态表达。
- **Do** 筛选与收藏反馈采用短过渡，具体时长待实现确认。
- **Do** 搜索无结果保留条件并提供清空或换词；加载失败可重试且保留输入；空收藏／草稿说明用途与下一步；内容处理中或下架明确说明并提供返回路径。
- **Do** 游客继续阅读，专属动作引导校园认证；作者主页与公开联系方式仅向认证用户开放，且联系方式须由作者主动公开。
- **Do** 明确标注前端示例数据，接口与真实状态待后端对接后验证。

### Don't:

- **Don't** 添加文章左右封面、图片占位块或空图片列，或在首页添加装饰插画。
- **Don't** 使用黄底白字、过浅黄色功能文字／图标、emoji 功能图标或持续装饰动效。
- **Don't** 公开真实校园邮箱或展示失效联系方式入口；空状态不填充假内容。
- **Don't** 为非现金校园币添加货币符号、充值或交易入口，或让奖励压过阅读与分享。
- **Don't** 将概念图中的示例认证、数据或界面理解为已实现能力。
