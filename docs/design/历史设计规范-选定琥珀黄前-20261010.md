# Design System: 城院帮

> 当前状态（2026-10-10）：用户不满意初版青绿及第一轮 A／B／C 配色。本轮已去掉文章左侧封面，改为全宽文字列表，并提供白底 D 莓红、E 鸢尾紫、F 琥珀黄三个候选。配色尚未选定。下文的青绿规则和含封面视觉稿作为初版历史记录保留，后续实现应先参照 [无封面布局与配色说明](docs/design/无封面布局与配色说明.md)，不要把初版青绿当成已确认主色。

## Overview

**Creative North Star: "认真整理的学长学姐经验册"**

以清晰的中文标题、连续经验列表、章节结构和留白体现品质，让读者先判断经验是否与目标岗位相关，再进入安静的长文阅读。校园插画和小封面辅助辨识主题，内容承担主要信息。

本文件描述实施前的概念设计。依据 [产品范围](PRODUCT.md)、[设计规格](docs/design/小程序设计资源与方案.md) 和 [四页视觉稿 v2](docs/design/城院帮-四页视觉稿-v2.png) 整理；精确数值来自设计规格，图像观察只说明构图与视觉语言。视觉稿为 AI 生成图片，没有可点击原型或源码，不代表功能已实现、已运行或经真机验证。图中人物、文章、认证状态及互动数均为虚构演示；作者总获赞（688）、总收藏（554）等修正值仍只是演示数据。投币图标应表达非现金校园币，不使用美元等货币符号。样式、文字或权限偏差以产品范围及设计规格为准。

**Key Characteristics:**

- 深青绿强调关键操作，浅灰绿底与白色内容表面保持轻盈。
- 中文信息优先，列表、标签和文章目录构成经验册的秩序。
- 校园插画只作辅助，不模拟纸张纹理或实体书本。

## Colors

配色以沉稳青绿为主，小面积杏色为封面与提示提供暖意。下表为待实现的规范值，未从图像取色或代码提取。

| 角色 | 规范值 | 用途 |
| --- | --- | --- |
| Primary · 深青绿 | `#096B5A` | 主要按钮、选中状态、品牌区域 |
| Secondary · 浅青绿 | `#E5F2EC` | 标签、摘要及轻量背景 |
| Secondary · 浅杏色 | `#F4EBDD` | 封面和小面积辅助提示 |
| Neutral · 清浅灰绿 | `#F4F7F5` | 页面底色 |
| Neutral · 白色 | `#FFFFFF` | 内容表面 |
| Neutral · 深墨绿 | `#172E27` | 主文字 |
| Neutral · 灰绿 | `#52675E` | 次级文字与元信息 |
| Neutral · 淡灰绿 | `#E3EBE6` | 分隔线 |

**The Clear State Rule.** 颜色不能独立表达选中、认证或异常，须同时提供文字、图标或明确形态。

## Typography

有意选择原生系统中文无衬线字体，以保障中文覆盖、加载速度及平台阅读习惯。iOS 优先 PingFang SC，Android 使用平台中文无衬线字体；不引入装饰性网络字体。图像中的字体效果不能视作已加载真实字体。

| 层级 | 规格 | 用途 |
| --- | --- | --- |
| 页面标题 | 24px | 页面主标题 |
| 文章标题 | 22px | 详情页题目 |
| 列表标题 | 17–18px；行高约 1.45 | 经验条目 |
| 正文 | 16px；行高约 1.7–1.8 | 长文阅读 |
| 辅助信息 | 12–13px | 作者、日期、标签等 |

视觉稿使用加重标题建立层级；具体字重尚未规定，留待实现确认。长标题及专业名称允许换行，必要时提供完整值的查看方式。

## Layout

以 390px 宽画板、左右 20px 边距为参考，使用 4、8、12、16、24、32px 间距尺度。保持单列阅读与清楚的内容分组。视觉稿以紧凑元信息、宽松章节间距和横向分隔组织内容。

四页信息层级如下，属于本轮页面方案：

| 页面 | 从主要信息到次级信息 |
| --- | --- |
| 发现 | 品牌与短引导 → 搜索 → 岗位筛选 → 同专业／公司次级筛选 → 重点经验 → 连续列表 → 底部导航 |
| 经验详情 | 岗位与阶段、题目、作者与阅读信息 → 摘要 → 准备／投递／面试／避坑目录与正文 → 点赞、非现金投币、收藏、评论 |
| 作者主页 | 头像、昵称、专业、背景 → 经验与互动概览 → 作者选择公开的联系方式 → 分享过的经验 |
| 我的 | 本人信息与认证状态 → 收藏／经验／草稿入口 → 非现金币及轻量每日奖励 → 写作入口 → 反馈与设置 → 底部导航 |

底部导航建议“发现／收藏／创作／我的”。图中可见“创作”写法偏差时按此规格处理。布局需在正式开发时转换和适配，不能将 px 简单翻倍视为适配完成；中文字体、小屏幕、长文案、微信胶囊及底部安全区仍需验证。

## Elevation & Depth

图中页面内主要依靠白色表面、浅青绿区域及淡分隔线区分层级。外部展示画板的投影不作为小程序阴影规范。当前没有精确阴影参数；实现时不凭概念图添加重阴影、磨砂玻璃或大面积渐变。

## Shapes

内容区域采用温和圆角（12–16px），短筛选标签使用胶囊形。封面保持规整小块，避免挤压经验标题和摘要；头像沿用图中的圆形语言。圆角只标识容器和操作范围，不让每段正文都变成独立卡片。

## Do's and Don'ts

### Do:

- **Do** 使用同一套线性功能图标，线宽约 1.5–2px；选中状态结合文字与形态表达。
- **Do** 为筛选切换及收藏反馈采用短过渡；具体时长待实现确认。
- **Do** 搜索无结果时保留条件并提供清空或换词；网络失败提供重试并保留输入；空收藏与空草稿说明用途和下一步；内容处理中或下架明确说明并提供返回路径。
- **Do** 未认证状态说明专属动作需要校园认证，并允许继续阅读；联系方式入口仅在作者选择公开且读者已认证时展示。

### Don't:

- **Don't** 用 emoji 代替功能图标，或持续播放装饰动效。
- **Don't** 公开真实校园邮箱、展示无效联系方式入口，或用假内容填充空状态。
- **Don't** 将非现金币设计成充值、交易入口，或让奖励与积分信息压过阅读和分享。
- **Don't** 把图片中的演示状态当成真实认证、互动数据或已实现能力。
