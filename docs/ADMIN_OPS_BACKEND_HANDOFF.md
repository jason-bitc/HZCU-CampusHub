```powershell
git fetch origin
git switch --track origin/codex/wc-admin-ops-integration
```

已有未提交前端工作时先保留，不强制切分支或覆盖；可另克隆到空目录查看接口。分支已存在则switch后使用pull --ff-only。复核合并main后，后续开发从最新main创建个人任务分支。
