# 城院帮微信原生小程序

沿用现有 WXML / WXSS / JavaScript 工程和 Java / Spring Boot / MySQL 后端。当前包含公开发现、完整阅读、校园账号、个人中心、资料与联系设置、点赞收藏、创作工作区、基础图文、评论回复、作者主页、硬币及账本，以及举报反馈、反馈进度、行为限制申诉和规则设置，共 15 个原生路由。独立 Vue 网页见 [web/README.md](../web/README.md)。

当前原型差距和分层验证见 [2026-11-07 原型对照](docs/PROTOTYPE-PARITY-20261107.md)。既有功能的接管记录见 [2026-11-06 接管记录](docs/TAKEOVER-20261106.md)。

## 运行

1. 用已安装的微信开发者工具导入本目录 `miniprogram`，不是仓库根目录，`miniprogramRoot` 为 `./`。
2. 共享 `project.config.json` 的 AppID 为占位值；核对本人已有的本机 private 配置及实际权限。没有修改、提交本机 AppID，也没有据此宣称手机预览权限已验收。
3. 按后端 `server/README.md` 与本机私密配置运行服务及 MySQL。健康接口 `/actuator/health` 应返回 `code=OK / data.status=UP`。反馈和申诉需要包含 `COMMUNITY_API.md` 与 `ADMIN_API.md` 新增用户治理接口的后端版本，本轮使用 [后端 PR #8](https://github.com/jason-bitc/HZCU-CampusHub/pull/8) 对应的本机版本验证。
4. 在 Git 忽略的 `config/local.js` 中配置前端服务地址：

```js
module.exports = {
  demoMode: false,
  apiBaseUrl: 'http://127.0.0.1:8080',
  webBaseUrl: 'http://127.0.0.1:5173', // 可选，用于复制用户网页创作入口
  requestTimeout: 10000,
  pageSize: 10,
  debug: false
};
```

这里不放数据库、SMTP、应用密码或令牌。开发调试地址的域名/HTTP约束与正式HTTPS、真机连通分别验证，不修改系统安全策略。

5. 配置切换后点击工具栏“编译”完整重编译。热重载期间的旧模块、旧页面和瞬时空白不能作为最终运行状态。
6. 使用真实互动与创作前，请关闭演示模式并重新编译。设置 `webBaseUrl` 后，复杂 Markdown 草稿可以复制网页创作入口。使用同一后端和校园账号登录网页后，在工作区继续编辑同一云端草稿。

## 页面与实际行为

| 入口 | 行为 |
|---|---|
| 发现 | 关键词、岗位、专业/公司/主题组合筛选、服务端认可/最新排序、分页、空结果恢复、返回保留；有效身份且本人已填专业时可用同专业快捷项 |
| 经验详情 | 全文、图片、来源链接、右上角44×44px方框目录及检索；游客不请求作者和评论；登录后读取本人互动、作者和投币状态 |
| 我的 | 资料与隐私、经验、草稿、收藏、反馈进度、每日奖励、硬币和贡献、反馈帮助与设置 |
| 登录/注册/找回密码 | 同一校园邮箱账号；只支持stu.hzcu.edu.cn；验证码由本人点击发送；注册成功回登录，重置成功要求重新登录 |
| 资料与隐私 | 昵称、专业、当前阶段、简介和独立联系设置；两个修订独立，不覆盖冲突；关闭联系可保留本人已填值，清空后保存可删除 |
| 收藏 | 本人分页；不可用项不含历史标题/摘要，可真实移除 |
| 创作 | 多篇草稿、幂等创建、按状态筛选、下架、恢复原公开版本、带修订校验的软删除 |
| 编辑与预览 | 基础图文、分类、经历阶段、来源与资料链接、图片上传/预览/重试、段落次序、完整草稿保存、本机副本、409对比和发布结果核对 |
| 复杂 Markdown | 只读预览和原文复制。可复制已配置的网页创作入口，用相同校园账号继续编辑 |
| 评论 | 文字/图片、主评论及平铺回复、本人删除；不可用占位不含旧正文；发送结果不确定时冻结原请求内容并沿用原键重试 |
| 作者 | 当前允许的基础资料、公开文章和实时联系开关；没有真实邮箱、头像、未确认荣誉或站内聊天 |
| 硬币 | 余额、贡献、规则、显式奖励领取、阅读计时、账本快照；投币有确认、余额和单篇额度检查，无购买、提现或自行撤回 |
| 举报与反馈 | 从原文或评论关联内容，或独立提交使用反馈。支持私有证据图片、本机输入恢复和提交结果核对 |
| 我的反馈 | 只读本人记录、说明、证据、处理时间线和公开答复 |
| 账号处理与申诉 | 查阅本人发布和评论限制，提交对应处理决定的申诉，跟踪公开复核结果 |
| 规则与设置 | 展开校园认证、内容、联系和硬币规则，进入资料、密码重置、反馈、申诉或退出 |

公司筛选只接受 catalog 中启用标签的 `companyId`，不发送任意公司文本。关键词检索标题和摘要。不带 `jobId=` 等空数字参数。

草稿中当前个人阶段与过去经历阶段分开确认。专业可默认来自本人资料，仍可调整；公司、主题、提示和资料链接可跳过。整理来源须说明，最终发布条件以真实后端校验为准。

## 会话、冲突与重试

- 私有请求显式使用 Bearer。公开接口继续使用游客字段，不把作者资料夹进公共响应。
- 令牌仅用于隔离存储和请求鉴权。401、账号访问受限或会话到期会清空私有页面，单独的发布或评论限制保留会话及本人申诉入口。
- 退出成功会真实撤销当前服务端会话并清理本机私有副本；网络失败明确区分“退出未确认”和“仅清理本机”，不伪称服务端撤销成功。
- 点赞、收藏等无正文接口完全不设置请求 `data` 属性；不能发送 `{}`、`null` 或空白正文。
- 资料、联系与草稿携带各自 `expectedRevision`。409只取最新版本并保留本机内容，由本人比较后决定；不自动用新revision重写。
- 创建、上传、发布、评论、投币、领奖、反馈和申诉使用独立 UUID。结果不确定时保留原键和原参数，发布核对前保留原草稿修订。重新选择文件使用新的上传键。
- 私有图片通过带鉴权的下载取得临时资源，绝不拼接URL令牌；会话变化和离页后清理显示资源。用户已经另存或复制的信息不能由服务器收回。
- 认证失效时可为原账号保留恢复副本，但隐藏正文；显式退出会清理这些私有副本。副本按服务地址和本人编号隔离，不冒充云端保存成功。

## 演示模式

`demoMode:true` 仅替换公开发现与详情数据，始终显示演示标识；这些示例详情不开放真实互动，避免对本机后端同号文章误操作。账号和本人工作区仍连接真实后端。真实接口模式失败不会回退演示数据。

原有 `scenario=normal/empty/network/service/unavailable` 只在演示公开页面生效。没有在正式页面增加故障切换工具。
