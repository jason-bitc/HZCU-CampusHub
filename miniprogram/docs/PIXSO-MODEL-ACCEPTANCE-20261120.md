## 复现

1. 微信开发者工具打开 `miniprogram`，私密配置指向本机 8080，`demoMode:false`，机型选择 iPhone 12/13 mini。历史基线截图见 [上轮布局验收](LAYOUT-ROLLOUT-20261117.md)。
2. 发现点「组合筛选」，选「Java后端开发（演示）」和「计算机科学与技术」。应用后打开文章 2009。阅读至中段，打开目录，选「十、投递前可执行的检查清单」，返回发现，再移除专业。输入无匹配关键词，随后清除条件。
3. 游客从文章中段选择登录，在原文章确认章节和收藏状态。打开「我的」，从「草稿」进入对应工作区并打开现有草稿。
4. 从「我的」打开通知，切换「未读」。接口失败时核对页面内原因、追踪标识及重试。
