# 2026-11-05 Codex 接管与整改

基线：`feat/ljh-frontend-foundation` / `c73cec5`。原有 WorkBuddy 预览标记、本机配置保留，不进入提交。范围为 M01、M03、M04、M05 和 S02 公开阅读状态；不扩展账号、互动、创作或管理功能。

## 设计规格

- 场景：发现与筛选为操作界面，详情为阅读界面。目的为找到符合岗位及背景的公开经验，并在失败后保留条件继续阅读。
- 视觉：沿用完整原型的编辑式阅读层级、青绿识别、白色内容区和自然换行，不更换视觉主题。
- 颜色：主色 `#0d6b57`，深主色 `#075342`，浅主色 `#e6f2ed`，正文 `#202723`，页面 `#f5f7f6`；辅助文字统一提高对比度。
- 字体：保留现有原生中文系统字体（PingFang SC / Microsoft YaHei 等）。这是项目及原生平台约束，优先于通用网页字体建议。正文 32rpx、行高 1.75；辅助文字不低于 24rpx；主要按钮点击高度至少 max(88rpx, 44px)。
- 布局：手机单列，4px/8rpx 间距基础，页边 24–32rpx；内容自然折行。阅读内容限制宽度，固定栏留足底部安全区。筛选正文独立滚动，目录遮罩锁定背景滚动。
- 反馈：原生按钮 hover-class；筛选只改草稿，应用后发请求，取消还原；失败、空结果、503、不可用独立呈现。未开放入口真正禁用，不响应点击。
- 开发辅助：演示模式保留清晰标识；状态切换只通过开发页面参数或开发工具调用，不作为阅读区中的交互入口。真实模式不显示开发说明。
- 本轮用户明确调整：删除正文开头的目录区，将阅读目录改为内容视口右上角 44×44px 小方框。点击后展开章节抽屉，不再使用大椭圆悬浮入口。该指示优先于原型中的开头目录。

依据：正式 SRS 的 FR-R01～06、FR-P03、NFR01/03/06；完整覆盖表及原始 M01/M03/M04/M05/S02 图片；当前 WXML/WXSS/JS；已运行的微信开发者工具 Stable 2.02.2608060 原生模拟器。UI/UX 检索只采纳适用的移动触控、行高、筛选标签换行建议；未找到专门的原生目录抽屉/筛选草稿数据库条目，相关行为按原型及微信能力设计，不套用网页框架。
