## 运行与复核

- 按 [运行说明](../README.md) 导入 `miniprogram`。真实模式需要包含社区案件及行为限制扩展的后端；健康检查以 `/actuator/health` 的 `data.status=UP` 为准。
- 从“我的”进入反馈进度或反馈帮助与设置。从可见文章或评论发起举报时，关联 ID 由入口传入。本人详情可展开证据，处理状态以实际回执为准。
- 从“我的经验”或“草稿”进入同一创作页。删除携带当前修订，服务端确认终态后清理对应本机副本。自主下架可恢复上次公开版本，管理员隐藏需要社区处理。
