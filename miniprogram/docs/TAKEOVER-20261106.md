## 合同与安全实现

- `request.js` 仅对 `auth:true` 的同一配置后端请求附带 Bearer；公开文章继续裁剪游客字段。未提供 `data` 时完全不设置该属性，避免 `{}` 破坏无正文合同。
- 会话只在 JS 内存及微信隔离存储中保留令牌/到期时间/最小本人编号，不放入页面 data、URL或日志。这里没有宣称本机存储是操作系统密钥库。应用重启和进入受限页面会重新核验身份。
- 请求和页面各自检查会话代次/页面代次。退出、身份变化及卸载后，晚到的私有响应不能恢复本人资料。
- 本机恢复副本按后端地址、本人编号和文章编号隔离。认证失效时隐藏编辑内容，原账号重新登录可恢复；显式退出清理本应用私有副本，不清理无关缓存。
- 私有图片用带请求头的 `wx.downloadFile` 取得临时文件。只允许配置后端的 media 路径，拒绝查询令牌；页面隐藏或会话变化后释放显示资源并尝试删除临时文件。不宣称能收回用户已复制或另存的信息。
- 注册成功只回登录表单；密码重置成功清理旧会话并要求重新登录。发送验证码无后台重试，202只表示请求受理。
- 资料、联系及草稿的409均不自动覆盖；创建、上传、发布、评论、投币、领奖的业务重试保留原请求键。投币成功回执后另查实时余额和状态。
