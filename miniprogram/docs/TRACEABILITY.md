## 用例与质量要求映射

| 用例 / 质量要求 | 本批落点 |
|---|---|
| UC01 查找与阅读经验 | 发现 → 筛选 → 排序 → 详情完整链路；返回发现页保留页面栈、筛选条件、已加载文章和滚动位置。 |
| NFR01 权限与私有数据 | `services/article-mapper.js` 只映射公开合同字段；页面不请求或展示作者昵称、头像、主页、联系方式和评论。 |
| NFR03 内容与文件安全 | `utils/markdown.js` 将正文解析为纯文本节点，不执行 HTML/脚本；只允许 http/https 外链；相对图片仅按配置后端地址解析。 |
| NFR06 双端兼容与可用性 | 原生 WXML/WXSS/JS；统一图标与安全区处理；长标题与长正文允许自然换行；图片失败有独立反馈与重试。 |
| FR-P03 规则说明与无结果提示 | 页面明确展示筛选不自动放宽、失败非空结果、游客权限边界及外部资料访问责任。 |

## 接口字段映射

| 后端字段 | 前端使用 |
|---|---|
| `jobs / majors / companies / topics` | 筛选选项、文章标签与详情分类。公司为空时显示“不限/无公司标签”，不伪造公司。 |
| `keyword` | 只发送去空白后的非空关键词；服务端检索标题与摘要。 |
| `sort=recognized` | 展示为“认可优先”；排序由服务端完成。 |
| `sort=latest` | 展示为“最新发布”；排序由服务端完成。 |
| `page / size / total / items` | 控制分页、总数、加载更多与去重；筛选或排序切换时 `page` 重置为 1。 |
| `sourceType / sourceNote / sourceLinks` | 展示来源类型、来源说明和可复制外链。 |
| `counts.effectiveLikes` | 列表展示公开认可数；游客响应不含本人 liked/favorited 状态，本批不伪造。 |

## 有意未实现入口

以下功能属于后续批次，本轮不提供空白入口，也不显示成可用：

- 登录、校园邮箱认证、认证失效处理。
- 点赞、投币、收藏与评论互动。
- 作者公开主页和联系方式。
- 小程序创作、草稿与图片上传。
- 收藏、创作、我的通知和个人工作区。

## 原型与当前接口差异记录

1. M03 原型中的公司为文本输入样式；当前公开接口只接受已启用分类的 `companyId`。本批按真实合同实现为公司标签选择，不新增后端不支持的文本筛选。
2. M01/M05 原型底部包含收藏、创作、评论等入口；这些能力依赖认证或互动接口，本轮按任务边界不实现，也不放入假 tabBar。
3. M05 原型含文章目录；本批按 Markdown 标题自动生成可折叠目录，目录仅来自当前公开正文。
4. 外部资料链接受小程序能力限制，当前提供“复制链接”和访问提示；不宣称可直接打开任意站外网页。
