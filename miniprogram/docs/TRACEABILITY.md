## 用例与质量要求映射

| 用例 / 质量要求 | 本批落点 |

## 接口字段映射

| 后端字段 | 前端使用 |
|---|---|
| `jobs / majors / companies / topics` | 筛选选项、文章标签与详情分类。公司为空时显示“不限/无公司标签”，不伪造公司。 |
| `keyword` | 只发送去空白后的非空关键词；服务端检索标题与摘要。 |
| `sort=recognized` | 展示为“认可优先”；排序由服务端完成。 |
| `sort=latest` | 展示为“最新发布”；排序由服务端完成。 |
| `page / size / total / items` | 控制分页、总数、加载更多与去重；筛选或排序切换时 `page` 重置为 1。 |
| `sourceType / sourceNote / sourceLinks` | 展示来源类型、来源说明和可复制外链。 |
| `counts.effectiveCoins / effectiveLikes` | 列表按原型展示公开投币数；游客响应不含本人投币/点赞状态，本批不伪造互动。 |
| `jobNature / baseLevel`（可选展示字段） | 若后端公开响应提供则展示“岗位性质/当时基础”；未提供时显示“岗位性质未标注/未填写”。当前公开 Java 合同尚无这两个字段，演示数据仅用于界面走查。 |

## 有意未实现入口

以下功能属于后续批次，本轮不提供空白入口，也不显示成可用：

- 登录、校园邮箱认证、认证失效处理。
- 点赞、投币、收藏与评论互动。
- 作者公开主页和联系方式。
- 小程序创作、草稿与图片上传。
- 收藏、创作、我的通知和个人工作区。

## 原型与当前接口差异记录

1. M03 原型中的公司为自由输入样式；当前公开接口只接受已启用分类的 `companyId`。本批提供公司名输入，并仅允许匹配到启用标签后发送 `companyId`；未匹配时明确阻止应用，不静默放宽或伪造文本筛选。
2. M01/M05 原型底部包含收藏、创作、点赞、投币、收藏、评论等入口；这些能力依赖认证或互动接口。本轮按任务边界不实现真实操作，仅提供禁用态并提示后续批次开放，不使用空白页伪装。
3. M05 原型含文章目录；本批按 Markdown 标题自动生成开头目录和阅读中固定目录入口，目录仅来自当前公开正文。
4. 外部资料链接受小程序能力限制，当前提供正文资料卡和“复制链接”；不宣称可直接打开任意站外网页。
5. M05 原型含“岗位性质/当时基础”；当前后端公开合同未定义这两个字段，前端按可选字段展示，缺失时明确标注，不把演示数据当成真实接口能力。
