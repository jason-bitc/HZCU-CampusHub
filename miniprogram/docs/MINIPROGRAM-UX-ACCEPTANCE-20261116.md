## 分层验收

- 自动检查。`node miniprogram/tests/run.js` 10 项，`node miniprogram/tests/behavior.js` 14 项，`node miniprogram/tests/member-behavior.js` 31 项。失败、重复点击、位置恢复和本机输入保护使用可控场景回归。
- 真实 HTTP。`node miniprogram/tests/real-api.js http://127.0.0.1:8080` 通过 21 个请求，涵盖健康、目录、5 页查询、筛选、全文及 400/404。另使用隔离账号核对 8 个真实请求，包含撤销状态、403 权限、通知、申诉答复和反馈进度。资料和图片保留原鉴权。
- 模拟器。微信开发者工具原生视图使用 `demoMode: false`、`http://127.0.0.1:8080`。验收机型配置为 320×568，运行时回读窗口宽度为 320 CSS 像素。发现与阅读 11 项、创作 6 项、通知与反馈 6 项、认证界面复查 2 项，共 25 项断言通过。
- 发现与阅读。先选 Java 后端，再开启同专业，真实结果包含 A01（文章 #2005）。选择最后一章，实测目录宽高均为 44 CSS 像素。收藏后从 8080 回读 `favorited=true`。返回发现保留岗位、专业和滚动位置；游客再从原文登录后回到同一文章和末章。基线无匹配关键词在新版本进入独立的无匹配状态。
- 创作。草稿 #2013 通过 8080 真实上传并保存图片，修订从 1 更新到 2 后，原会话携带修订 1 保存收到 HTTP 409。界面保留标题、原正文、新增文字和图片引用，并自动定位到云端版本与本机副本。冲突追踪号 `a6b8a78f-c381-4eea-971a-66821b6a1eea`。选图输入由模拟器提供，上传、草稿保存和冲突均由真实服务处理。
- 通知、反馈和认证。模拟器由未读通知进入本人反馈 #5，返回真实接口核对该条已读时间。隔离账号登录后可读取撤销原因和原申诉答复，普通资料 GET `/api/v1/me` 返回 HTTP 403 `ACCESS_RESTRICTED`，追踪号 `a4aceda0-b14e-487f-95cf-b6670ac3423d`。

## 复现步骤

1. 以有专业的校园测试账号打开发现，选择 Java 后端岗位，再打开与关闭同专业。分别移除筛选标签、清除全部条件和切换排序。输入一个无匹配关键词，对照空态。用行为测试让刷新返回失败，再重试当前条件。
2. 打开演示 A01 长文，展开目录，选择末章，重新展开核对高亮，收藏并从本人状态接口回读。返回确认列表条件与位置；退出后重新从原文进入登录，核对回到同一篇和同一章节。
3. 在创作新建隔离草稿，录入标题与正文，打开预览，点击一条缺项核对定位。选用已授权的 JPEG/PNG 上传并保存。用第二个会话按当前修订修改同一草稿，再从模拟器按旧修订保存，核对 409、原正文和图片引用，展开云端版本。
4. 用隔离测试账号查看反馈结果通知，由通知打开本人案件进度，并复查服务端已读时间。用已撤销认证的测试账号登录，查看撤销理由、站内通知及关联的复核答复。
