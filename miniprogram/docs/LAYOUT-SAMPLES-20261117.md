## 复现步骤

1. 在微信开发者工具打开 miniprogram，底部机型选 iPhone 12/13 mini。使用本机真实服务配置和校园测试账号，打开「发现」并清除条件。
2. 点「岗位」选 Java 后端，再点「只看同专业」。检查两项标签、组合筛选和「全部岗位」只清除岗位。切换排序、滚动后打开 2005 号长文，再返回核对列表位置。阅读目录按实际渲染测量。
3. 搜索 G04布局验收无匹配7162143 触发真实无匹配。用模拟器请求调试分别返回 503 与零公开文章，核对错误保留条件、空库文案和恢复真实请求后的重试。
4. 打开「我的」，核对硬币和收藏接口，点击账号卡进入资料及联系设置。进入「我的限制与申诉」查看两个分区。滚动到底，核对最后一项与底栏。

## 分层结果

- 自动化 57 项通过。工程 10 项，行为 15 项，会员行为 32 项。新增岗位选择器传递分类 ID、同步选中项和保留其他筛选的回归。
- 真实 API 21 条通过，覆盖健康、目录、分页、组合筛选、公开详情及预期 400／404。个人中心的可用硬币与收藏总数另外与本人接口回读一致。
- 375px 实际运行。胶囊为 87×32 CSS px，左缘 281、右缘 368、上缘 51。系统安全区下缘 778，设备高度 812。搜索、快捷岗位、同专业、组合筛选四项实测均至少 44×44 CSS px。阅读目录为 44×44 CSS px。有实际文章、长标题、无匹配及服务清单截图。岗位与同专业叠加、组合筛选、非零列表滚动恢复、资料与联系、行为限制和申诉记录分区均完成走查。
- 模拟器接口注入。503 错误后保留原关键词和追踪号，恢复后按原条件重试。注入零公开文章以核对空库视图，随后恢复真实列表。注入只在模拟器使用，服务端数据未用于制造故障。
