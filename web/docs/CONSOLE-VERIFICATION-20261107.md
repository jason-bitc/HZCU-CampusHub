# 三端隔离与管理网页联调

2026-11-07。前端基线 `def0f246940a880eca9caa190458c181db732f02`。后端为 [PR #8](https://github.com/jason-bitc/HZCU-CampusHub/pull/8) 的 `b487c3b561225e07c98be7fe1df56db559929836`，构建 SHA256 为 `C7E46857E4748656FFFFA80CBBDFC7485176D3546C1575D224E18D6058AE9CFC`。真实联调使用 `campushub_test`、业务 8082、运维 8092 和本轮独立运行目录。

| 差距 | 处理 | 实际验证 |
| --- | --- | --- |
| 用户页暴露控制台 | 移除页脚入口，三个端口分别构建、挂载路由并代理各自 API | 用户端输入管理路径回到发现页，管理 API 返回 404，用户构建无管理路由及会话标识 |
| 文章仅标题可点 | 整卡可进入阅读，悬停及聚焦强化边框，右下圆形回顶 | 桌面悬停、摘要点击、键盘进入、收藏点击保留在发现页。窄屏检查无页面横向溢出，回顶不压住页脚 |
| 管理只有案件和原型占位 | 接通总览、巡查、分类、限制、申诉和审计 | 真实认领与结案约束，文章和评论隐藏恢复，分类新增改名排序停用，评论限制与接受对应版本申诉 |
| 运维只有原型 | 接通独立登录、状态、日志、确认、持久任务和四种受控动作 | 真实部署、PID 重启、备份及恢复。恢复前后检查同一测试分类名，确认返回备份值 |
| 写操作回执可能丢失 | 保留原对象、修订和幂等键，运维保留原确认及请求键 | 两处有意丢弃实际成功回执，刷新后以原请求核对。治理仅一条事件，备份返回同一任务编号 |

测试以随机校园身份发布明确标记的演示文章。评论和举报测试对象经真实 API 创建，页面完成后续治理。测试文章最后下架，三个网页会话退出。治理审计、测试分类、任务和保护清单保留在测试环境。没有使用真实邮件。

运维 JAR 的 `PropertiesLauncher` 启动方式在本机通过登录和状态读取，部署预检查返回 `OPS_EXECUTION_FAILED`。JFR 记录到 `java.sql.SQLException` 的 `No suitable driver`。隔离测试解出同一 JAR 的类和依赖，使用普通 Java 类路径启动独立控制器。最初缺少测试 SMTP 启动字段的失败和保护清单单独保留。随后用仅回环的占位 SMTP 配置启动隔离业务，四类运维任务成功。真实网页结果与原启动方式的问题分别记录。
