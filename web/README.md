# 城院帮网页端（读者、作者与独立管理前端）

在现有仓库新增独立 `web/`，采用 Vue 3 + TypeScript + Vite；没有重新生成或转换原生小程序。读者作者结构依据 W01–W08，社区与运维依据 A01–A08 / O01–O10 原型。本机开发直接连接现有 Java / Spring Boot / MySQL 后端，不提供自动模拟数据回退。

## 运行

需要 Node.js 22.18+、npm、已运行的业务后端和对应授权账号。在 `web` 目录运行 `npm ci`，然后按需在独立终端启动。

| 页面 | 命令 | 本机入口 | 默认代理 |
| --- | --- | --- | --- |
| 普通用户 | `npm run dev` | `http://127.0.0.1:5173/` | 业务 8080，普通 API |
| 社区管理 | `npm run dev:admin` | `http://127.0.0.1:5174/#/admin/login` | 业务 8080，社区管理 API |
| 独立运维 | `npm run dev:ops` | `http://127.0.0.1:5175/#/ops/login` | 独立运维 8091 |

普通用户页面没有管理导航。三端在构建时选择各自路由与产物，并在对应端口单独登录。社区管理需要 PR #8 提供的 V11 后端。运维按 `server/OPS_API.md` 初始化，配置 `allowedOrigin` 为 `http://127.0.0.1:5175`。运维只能管理自身登记并启动的业务目标。

非默认本机端口写入 Git 忽略的 `.env.local`，分别使用 `CAMPUSHUB_API_TARGET` 和 `CAMPUSHUB_OPS_TARGET`。修改后重启对应 Vite。密码、令牌和邮件配置留在本机私密文件。

```powershell
npm test
npm run build
```

构建输出分别在 `dist/user`、`dist/admin`、`dist/ops`。本机可用 `npm run preview`、`npm run preview:admin`、`npm run preview:ops` 查看，对应端口 4173、4174、4175。使用 4175 预览运维时，服务端 `allowedOrigin` 同步设为 `http://127.0.0.1:4175`。静态部署分别发布三份构建并配置同源代理，管理和运维访问受对应网络及后台授权控制。

## 已开放的真实功能

| 路径 | 行为 |
| --- | --- |
| `/#/` | 搜索标题/摘要，岗位/专业/公司/主题组合筛选，认可/最新排序，分页；条件写入 URL，空结果清除、失败重试 |
| `/#/articles/:id` | 完整 Markdown、代码块/表格/列表、安全外链、来源资料、44px 紧凑目录；登录后点赞收藏 |
| `/#/account` | 校园邮箱登录、注册、验证码、重置密码；验证码由本人点击发送；注册后仍需登录 |
| `/#/workspace` | 本人文章与草稿、状态筛选、新建、下架、恢复上次公开版本；状态筛选作用于当前分页，界面明确说明 |
| `/#/editor/:id` | 完整 Markdown 双栏编辑与安全预览、分类和来源资料、真实图片上传/Blob 私有预览、草稿保存、409 双版本比较与手动合并、确认发布 |
| `/#/favorites` | 发现列表/正文直接收藏，5/10/20条分页、返回恢复、末页回退和取消；不可用项严格最小占位 |
| `/#/me` | 本人资料和联系设置、硬币余额及贡献读取、退出当前会话 |
| `/#/me/appeals` | 本人行为限制、发起申诉、查询复核结果 |

## 社区管理与独立运维

社区管理包含案件、文章和评论巡查、隐藏恢复、四类分类维护、行为限制、申诉复核和治理审计。运维包含独立登录、状态、日志、登记版本、备份清单、操作确认与持久任务。部署、重启、备份、恢复均以后台任务结果为准。贡献失效、荣誉规则、分类合并、每日自动备份和离机副本仍待接入。

控制台右上角可进入 `?preview=1` 只读原型示例。默认页面展示实际接口结果，示例页有独立标记且不请求 API。发现页卡片支持悬停反馈、整卡进入阅读及独立收藏，滚动后右下角显示回顶按钮。

完整路由、端口与运维启动差异见 [控制台接入说明](docs/CONSOLE-INTEGRATION.md)。上一轮原型、收藏与阅读证据仍位于原路径。

Token 仅保存于当前标签页的 `sessionStorage`；刷新恢复，关标签页不会继续保留该端登录。会话到期、401 或账号认证受限会清理私有状态。两个客户端共享账号和业务数据，会话分别登录。

编辑恢复副本与幂等请求键同样保存在当前标签页，并按本人 ID 区分；退出会清除。请在关标签页或退出前下载重要草稿副本。没有承诺本机副本一定成功写入，云端保存以真实响应为准。发生 409 时不会自动覆盖新版本。上传结果不确定时重新选择原图，以原键和文件摘要重试；发布不确定时保留原键及原修订，刷新后也可恢复核对。

## 可复用的真实浏览器检查

```powershell
# 私密 JSON 可以是 {"email":"...","password":"..."} 或该对象的单元素数组。
$env:CAMPUSHUB_WEB_CREDENTIAL_FILE='本机忽略的私密文件绝对路径'
node tests/real-browser.mjs
```

该命令需要本机已有 Google Chrome 和已注册校园测试账号，**会真实创建、编辑、上传图片、发布并最终下架一篇标记 DEMO 的测试文章**，会临时点赞收藏再取消；不发送邮件、不领取奖励、不投币、不修改原有个人资料。创建与测试轨迹保留在后端。设置 `CAMPUSHUB_WEB_FIXTURE_ID` 仅可复用本脚本标记的草稿/下架文章。私密文件不入 Git，脚本输出仅保留方法、路径、状态和 traceId。

测试中两处有意丢弃真实后端已接受的上传/发布响应，再走界面重试；不是用模拟成功响应替代后端。此项与真实网络故障、邮件收件、真机浏览器和部署验收分别记录。
