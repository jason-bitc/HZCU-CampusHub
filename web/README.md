# 城院帮网页端（第一批读者与作者功能）

在现有仓库新增独立 `web/`，采用 Vue 3 + TypeScript + Vite；没有重新生成或转换原生小程序。结构依据 W01–W08 原型。本机开发直接连接现有 Java / Spring Boot / MySQL 后端，不提供自动模拟数据回退。

## 运行

需要 Node.js 22.18+（本轮实际使用 24.19.0）、npm 和已运行的项目后端。

```powershell
cd C:\Users\wangc\Desktop\HZCU-CampusHub-Frontend\web
npm ci
npm run dev
```

打开终端打印的 `http://127.0.0.1:5173/`。开发和本机构建预览均把 `/api` 代理到 `http://127.0.0.1:8080`，无需改后端 CORS。如需其他本机后端地址，复制 `.env.example` 为忽略的 `.env.local` 并修改 `CAMPUSHUB_API_TARGET`，然后重新启动 Vite。不要把密码、令牌或邮件配置放进任何 `VITE_*` 变量。

```powershell
npm run typecheck
npm test
npm run build
npm run preview
```

构建预览默认 `http://127.0.0.1:4173/`。网页采用 Hash 路由，刷新深层页面不会要求静态服务器重写路径。生产环境仍需 HTTPS 和同源 `/api` 反向代理；本轮没有部署或发布公网网站。

## 已开放的真实功能

| 路径 | 行为 |
| --- | --- |
| `/#/` | 搜索标题/摘要，岗位/专业/公司/主题组合筛选，认可/最新排序，分页；条件写入 URL，空结果清除、失败重试 |
| `/#/articles/:id` | 完整 Markdown、代码块/表格/列表、安全外链、来源资料、44px 紧凑目录；登录后点赞收藏 |
| `/#/account` | 校园邮箱登录、注册、验证码、重置密码；验证码由本人点击发送；注册后仍需登录 |
| `/#/workspace` | 本人文章与草稿、状态筛选、新建、下架、恢复上次公开版本；状态筛选作用于当前分页，界面明确说明 |
| `/#/editor/:id` | 完整 Markdown 双栏编辑与安全预览、分类和来源资料、真实图片上传/Blob 私有预览、草稿保存、409 双版本比较与手动合并、确认发布 |
| `/#/favorites` | 本人收藏分页与取消收藏；不可用收藏只展示合同允许的占位信息 |
| `/#/me` | 本人资料和联系设置、硬币余额及贡献读取、退出当前会话 |

Token 仅保存于当前标签页的 `sessionStorage`；刷新恢复，关标签页不会继续保留该端登录。会话到期、401 或账号认证受限会清理私有状态。两个客户端共享账号和业务数据，会话分别登录。

编辑恢复副本与幂等请求键同样保存在当前标签页，并按本人 ID 区分；退出会清除。请在关标签页或退出前下载重要草稿副本。没有承诺本机副本一定成功写入，云端保存以真实响应为准。发生 409 时不会自动覆盖新版本。上传结果不确定时重新选择原图，以原键和文件摘要重试；发布不确定时保留原键及原修订，刷新后也可恢复核对。

## 可复用的真实浏览器检查

```powershell
# 私密 JSON 可以是 {"email":"...","password":"..."} 或该对象的单元素数组。
$env:CAMPUSHUB_WEB_CREDENTIAL_FILE='本机忽略的私密文件绝对路径'
node tests/real-browser.mjs
```

该命令需要本机已有 Google Chrome 和已注册校园测试账号，**会真实创建、编辑、上传图片、发布并最终下架一篇标记 DEMO 的测试文章**，会临时点赞收藏再取消；不发送邮件、不领取奖励、不投币、不修改原有个人资料。创建与测试轨迹保留在后端。设置 `CAMPUSHUB_WEB_FIXTURE_ID` 仅可复用本脚本标记的草稿/下架文章。私密文件不入 Git，脚本输出仅保留方法、路径、状态和 traceId。

测试中两处有意丢弃真实后端已接受的上传/发布响应，再走界面重试；不是用模拟成功响应替代后端。此项与真实网络故障、邮件收件、真机浏览器和部署验收分别记录。
