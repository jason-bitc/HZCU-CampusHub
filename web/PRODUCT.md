# 城院帮读者与作者网页

## Platform

Web，独立于微信原生小程序；共享 Java / Spring Boot / MySQL 后端和校园账号。

## Users and purpose

面向杭州城市大学学生，按岗位、专业、公司与主题寻找校园求职经验；作者在桌面端编辑完整 Markdown、预览并公开发布。全文免费。硬币不能购买、提现或兑换现金。

## Stack

遵循 docs/FRONTEND_TECH_STACK.md：Vue 3、TypeScript、Vite。沿用既有 W01–W10 原型的结构与青绿色视觉；不使用 CloudBase，不把 WXML 当作网页组件。

## Confirmed scope

本轮实现发现与阅读、校园认证、本人资料与联系设置、点赞收藏、工作区、完整 Markdown 编辑、图片上传、安全预览、修订冲突、发布与下架恢复。只连接真实接口，不用模拟内容代表联调成功。网页支持本人限制及申诉，评论发布、作者主页、硬币账本、通知和反馈后续实现。社区管理和运维按 A01–A08/O01–O10 组织，接入已交付的真实后端合同。普通用户、社区管理、运维各自使用独立的网页端口。

## Constraints

验证码仅由用户明确点击发送；注册成功仍需登录。私有图片使用 Bearer 下载后的临时 Blob；退出清理本网页私有数据。409 不自动覆盖。创建、上传、发布保留幂等请求键。原型示例姓名与统计不当作真实接口字段。

管理账号与校园账号独立存储与请求，直接进入管理路由不恢复校园会话。运维仅接收独立运维身份。受控操作先展示服务器确认和影响，再提交持久任务，保留原请求键用于核对。原型示例必须由明确模式标记与真实接入状态分开，示例不产生业务写入。
