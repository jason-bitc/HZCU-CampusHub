# 城院帮读者与作者网页

## Platform

Web，独立于微信原生小程序；共享 Java / Spring Boot / MySQL 后端和校园账号。

## Users and purpose

面向杭州城市大学学生，按岗位、专业、公司与主题寻找校园求职经验；作者在桌面端编辑完整 Markdown、预览并公开发布。全文免费。硬币不能购买、提现或兑换现金。

## Stack

遵循 docs/FRONTEND_TECH_STACK.md：Vue 3、TypeScript、Vite。沿用既有 W01–W10 原型的结构与青绿色视觉；不使用 CloudBase，不把 WXML 当作网页组件。

## Confirmed scope

本轮实现发现与阅读、校园认证、本人资料与联系设置、点赞收藏、工作区、完整 Markdown 编辑、图片上传、安全预览、修订冲突、发布与下架恢复。只连接真实接口，不用模拟内容代表联调成功。网页评论、作者主页、硬币奖励账本、通知和反馈后续实现。用户新增授权社区管理与独立运维前端：按A01–A08/O01–O10还原，现有社区案件接口独立登录接入；后续治理及运维接口尚未开发，由用户后续补充。未接入功能不能显示真实成功。

## Constraints

验证码仅由用户明确点击发送；注册成功仍需登录。私有图片使用 Bearer 下载后的临时 Blob；退出清理本网页私有数据。409 不自动覆盖。创建、上传、发布保留幂等请求键。原型示例姓名与统计不当作真实接口字段。

管理账号与校园账号独立存储与请求，直接进入管理路由不恢复校园会话。运维授权接口未提供时不采集凭据、不构造假Token、不发起部署、重启或恢复。原型示例必须由明确模式标记与真实接入状态分开，示例不产生业务写入。
